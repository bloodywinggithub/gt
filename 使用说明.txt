老干部活动中心 使用说明
制作者：痛风老大爷
================

这是一个练电吉他用的小程序：吉他插声卡，程序里搭效果器链（单块、NAM 箱头模型、箱体 IR、VST3 插件），
带鼓机，还能打开 Guitar Pro 吉他谱，用“音游”一样的滚动谱面跟着练。

一、电脑要求
  - Windows 10 / 11，64 位。不用另外安装运行库，解压就能用。
  - 一块声卡（音频接口），吉他插在乐器（Hi-Z / INST）输入口。
  - 最好有声卡自带的 ASIO 驱动（去声卡官网下载），延迟最低。
    没有的话可以装免费的 ASIO4ALL 或 FlexASIO，或者直接用 WASAPI（延迟会大一些）。

二、第一次打开
  1. 解压整个文件夹（不要在压缩包里直接双击运行），双击 LianqinHost.exe。
  2. 如果出现“Windows 已保护你的电脑”：点“更多信息”→“仍要运行”。
     （程序没有购买数字签名证书，所以 Windows 会这样提示一次。）
  3. 点右上角“音频设置…”：
       设备类型选 ASIO → 选你的声卡 → 缓冲区选 128（卡顿就调到 256）。
       在“Active input channels”里勾选吉他插的那一路。
  4. 左边“吉他输入通道”选好那一路，弹一下，看输入电平表有没有跳。
     电平经常顶红就把声卡上的增益旋钮调小一点。

二（续）、桌宠（左下角戴贝雷帽的猫）
  - 它是个严厉的监工老师：嘴很毒，弹对了也只是勉强点头，弹错了、偷懒了都会挨说。
  - 平时端着咖啡：会呼吸、轻轻摇晃，杯子冒热气，时不时抿一口、歪头、小跳一下。
  - 你弹琴的时候它跟着点头；鼓机在走时跟着拍子晃。
  - 半分钟没动静会开始看表催你，一分多钟没动静就托着腮发呆打瞌睡；一弹琴它就醒过来。
  - 弹奏判定（练习谱面）：Perfect 比耶、Good 摆手、抢拍竖手指、拖拍掏怀表、错音捂脸、漏弹看表、每 10 连击摇滚手势，
    头上的气泡会刻薄你一句（抢拍 / 拖拍会写早 / 晚多少毫秒）。判定来得很快时动作会合并，不会乱闪。
  - 指板音阶的跟弹练习、认音训练、吉他和弦的“听我弹”也会让它有反应。
  - 点它一下会理你；右键可以隐藏，隐藏后点“显示桌宠”再叫出来。
  - 想换成别的形象：在程序旁边建 音色库\桌宠\ 文件夹，放同名的透明 PNG
    （normal、perfect、good、early、late、wrong、miss、combo 八张，底边对齐），就会用你的图。

三、音色 · 鼓机
  - 上方预设栏可以切换 / 保存音色。
  - 效果器拖动可以换顺序，单击开关，双击放大调参数，右键有更多选项。
  - 最后的“添加效果”里可以加 NAM 模型（音色库\NAM 里自带了一些）、箱体 IR、VST3 插件。
  - Gervana 系列（官方授权）在“添加效果”最上面，右边标着类型：
      失真：戊寅 法兹、丙子 过载    箱头：戊午 Plexi、乙酉 Brown Sound、乙卯 AC30    动态：甲辰 压缩激励
      空间：辛亥 混响 / 延迟（No.85，横版）——粉色一组是弹簧混响（衰减 / 混响量 / 音色 / 预延迟），
            蓝色一组是带调制的延迟（时间 / 反馈 / 延迟量 / 音色 / 调制速度 / 调制深度，调制让重复音像磁带一样漂）。
            左边脚踩开关混响，右边脚踩开关延迟，两个模块各管各的；关掉后余音会自然放完。
      同类型的 Gervana 也会出现在对应分组（失真 / 箱头 / 动态 / 空间）的最上面。
  - 下面是停靠栏，右上角三个页签切换：
      鼓机：选风格、调速度，空格键开始 / 停止。
      循环 ×5：五轨循环录音（用法见第五节），在这里调音色时也能录循环。键盘 1–5 按轨，0 全部播放 / 停止。
      音频伴奏：点“导入伴奏…”（或者把 MP3 / WAV / FLAC / OGG 文件直接拖进窗口），跟着一首歌或伴奏弹。
        点波形跳到那里，在波形上拖一段 = A-B 循环；“整首循环”、变速 50–150%（像磁带一样会跟着变调）、音量。
        伴奏不过效果器，直接进声卡输出。P 键播放 / 暂停。上次用的伴奏下次打开会自动载入。

四、练习谱面
  - 点顶部“练习谱面”，再点“打开谱子…”，或者直接把 .gp3/.gp4/.gp5/.gpx/.gp 文件拖进窗口。
  - “谱库…”：列出“吉他谱”文件夹里所有的谱子（包括子文件夹），按分类筛选、输入歌名 / 歌手搜索，双击打开。
    自己的谱子放进“吉他谱”文件夹就行，建子文件夹就是分类。
  - 没有谱子？点“在线找谱…”，输入歌名，选一个网站（吉他社、Songsterr、Ultimate Guitar、必应）。
    浏览器会打开搜索结果，你在网页上下载 .gp / .gp5 / .gpx 文件后，程序会自动把它放进“吉他谱”文件夹并打开。
    （有的网站要注册登录或会员才能下载。浏览器下载位置不是“下载”文件夹的话，在搜索框里点“换文件夹…”。）
  - 谱面有两种显示（右边“音游 / 六线谱”切换，T 键）：
      音游：木纹指板上每根弦一条轨道（上面是 1 弦），品丝就是小节线，数字是品位，音符滚到白色判定线时弹。
      六线谱：像纸上的吉他谱一样一行行排，下面画节奏符干，蓝色光标跟着播放走，整页自动往下翻；
        点哪一小节就跳到那里。弹奏判定照常：判过的数字按结果上色（金 = Perfect，绿 = Good，橙 = 错音，红叉 = 漏弹）。
    音符上面的小字是音名（例如 E4、C#3），不想看可以关掉“音名”（N 键）。
    击弦 / 勾弦 / 点弦：两个音之间画一道弧线，中间标 H（击弦）/ P（勾弦），点弦标 T。
    推弦：音符后面那条弦真的会被“推起来”，弯到推的高度（全音 ≈ 推到相邻弦的位置），顶上写“½音 / 全音 / 1½音”，
      放回来有向下的箭头；弹到的时候判定线上那根弦会跟着弯。打开弹奏判定时，推完会显示“到位”或者“差 ¼ 音”。
    PM = 闷音，× = 死音，菱形 = 泛音，斜线 = 滑音（细线 + 竖线 = 换把滑音，目标音要拨）。
  - 谱子里写了和弦（Guitar Pro 的和弦图）：音游模式左上角显示当前和弦的指法图和下一个和弦，六线谱上方写和弦名。
  - “示范音”：播放你选的那一轨；关掉就只剩伴奏，你来弹。
  - 一首谱子有好几条音轨时，音轨菜单最上面的“全部音轨（合奏）”可以全部一起听；
    旁边的“混音…”能单独调每条音轨的音量、静音（M）、独奏（S）。
  - 速度可以降到 25%；A / B 设置循环段，也可以在下面进度条上直接拖动框选。
  - “原曲…”（录音按钮那一排）：给谱子配上这首歌的原曲音频，点播放时原曲和谱子一起走：
    放慢时原曲也跟着慢、音高不变；A-B 循环、跳小节、预备拍都跟着。O 键开 / 关原曲。
      扒谱生成的谱子会自动配好原曲、对齐好；别处下载的谱子，选好原曲后在弹出的面板里
      用“开头”按钮（±1 / 0.1 / 0.01 秒）把第一拍对上，越往后越偏就调“快慢”。
      对齐信息存在谱子旁边的“谱子名.sync.json”里，下次打开自动带上（文件夹整个搬走也找得到）。
      只适合速度基本不变的歌；现场版那种越弹越快的，后面会慢慢对不上。想只听原曲就把“示范音”关掉。
  - 弹奏判定（默认开）：程序听你弹，判定线上会显示 PERFECT / GOOD / 错音 / MISS，右上角是命中率和连击。
    第一次用先点“延迟校准…”，跟着节拍器每拍拨一下空弦，共 16 下，判定会准很多。
    “等待模式”：弹对了才往下走，适合刚学一首歌的时候。弹完整首会出成绩卡，可以一键循环练最差的小节。
  - 谱面上滚鼠标滚轮可以调音符间距。
  - 快捷键：空格 播放/暂停，← → 上/下一小节，Home 回到开头，A / B 设循环点，↑ ↓ 调速度，W 等待模式，N 音名，T 音游 / 六线谱，O 原曲开关，E 改谱。
  - 贝斯谱：打开贝斯谱（或在“音轨”里选贝斯那一轨），指板自动变成 4 弦 / 5 弦（按谱子的定弦），
    左上角写“贝斯 · 4 弦”，弦越低画得越粗；六线谱模式也跟着变成 4 / 5 线。判定照样能用（低到 B0 都听得出来）。
  - “扒谱…”（音频扒谱）：选一首歌或一段录音（MP3 / WAV / FLAC / M4A…），扒成谱子，存在“吉他谱\扒谱”里
    （GP3 格式，Guitar Pro / TuxGuitar 也能打开改），马上打开就能跟着练、放慢、A-B 循环。
      现在用的是 AI 复音识别（Spotify 开源的 Basic Pitch 模型）：同时响的几个音都能扒出来，扫弦会扒成和弦，
      还会按声音自动分轨：
        · 左右声道各一把吉他 → 分成两条音轨，和弦多的那把叫“节奏吉他”，单音多的叫“主音吉他”；
        · 同一个声道里既有扫弦又有旋律 → 和弦的部分放“节奏吉他”，高出来的单音旋律放“主音吉他”；
        · 有贝斯 → 单独一条 4 弦“贝斯”音轨；
        · 每拍的和弦名（大三 / 小三 / 属七 / 强力和弦）写在谱上，配好指法图。
      扒谱对话框里的“分轨”可以选：自动分轨 / 只要主旋律（老的单音算法）/ 所有音放一条。
      可以选用哪路声音：混音 / 左声道 / 右声道 / 侧边；速度自动估计，也可以手动填 BPM；可以只扒一段。
      AI 识别要程序旁边的 onnxruntime.dll（压缩包里带了，别删）；没有这个文件会自动退回老的单音算法。
      乐器分离（可选，推荐）：下载“老干部活动中心-分离模型-htdemucs6s.zip”（约 130 MB），解压到程序所在的文件夹，
        程序旁边会多一个 models 文件夹。之后扒谱对话框里选“先分离乐器”：先用 Demucs 把歌分成
        鼓 / 贝斯 / 吉他 / 钢琴 / 人声 / 其他，再只拿吉他去扒、贝斯单独扒、按鼓找拍子。
        全部在本机算，不联网；一首 3 分钟的歌大约要 1–3 分钟（电脑越新越快）。
      节奏：按鼓和起音找出每一拍（速度慢慢变的现场录音也跟得上），整体拖拍 / 抢拍会先扣掉再对齐格子；
        Shuffle / 三连音感觉的节奏会扒成三连音。
      准不准（拿 7 段有原谱的示范录音测的，先分离乐器）：吉他大约 3–6 成的音对，贝斯约一半（硬摇滚）；
        比不分离时多对 5–10 个百分点，贝斯好得最明显。也有分离后反而差一点的录音，可以两种都试试。
      分轨是按声音特征猜的，混在一起的两把吉他不一定分得开。扒出来的谱当参考：原曲已经自动配好（见上面“原曲…”），
      放慢循环对着听一遍，用下面的“改谱”直接在六线谱上改。
  - “✎ 改谱”（E 键，录音那一排右边）：在六线谱上直接改谱子，改完存成 GP3。
      点音符的数字选中（Shift 点 / 拖一个框可以多选），点空白处是放光标；
      数字键：改品位（两位数连着按，比如 1 2 = 12 品）；光标在空白处时直接加一个音；
      Delete 删除；← → 上 / 下一个音；Shift + ← → 往前 / 往后挪一格；↑ ↓ 换弦；Ctrl + ↑ ↓ 换到相邻的弦、音高不变；
      + / - 品位升降半音；[ ] 时值减半 / 加倍（上面也能选时值、吸附的格子）；H 击弦 / 勾弦；X 闷音；B 推弦（全音 → 半音 → 不推）；
      C 或者双击谱上方和弦那一行：设和弦（选根音和类型，自动配指法图）；
      Ctrl + Z 撤销，Ctrl + Y 重做，Ctrl + S 保存，Esc 完成。空格照样可以播放听效果。
      保存：扒谱生成的谱直接覆盖；别的谱另存一份“原名（改）.gp3”，原文件不动，原曲同步也跟着带过去。
      反复记号会展开成一路写下去；GP3 格式存不了闷音标记（P.M.），其他（推弦、击勾弦、滑音、三连音、变速）都保留。

五、录音、速度阶梯、练习记录
  - “● 录音”：录下你弹的原声（不带效果），再点一下停止。先按录音再按播放，回放时谱子会对上。
  - “回放…”：选一段录音播放，录音会代替吉他走现在的效果器链，可以边听边换音色、换预设。
  - “循环 ×5”：五轨循环录音（Looper），录的是带效果器的声音，下面会出现 5 条轨：
      第 1 轨按“● 录”开始，再按一下定下循环长度并开始循环；
      第 2–5 轨按一下从当前位置开始录，录满一圈自动转播放；正在播放的轨再按一下是叠录，再按结束叠录。
      每轨有静音（M）、清除（×）、音量；“跟鼓机对齐”打开时，鼓机在走就等下一小节第一拍开录，长度取整到整小节。
      “导出 WAV”把几轨混成一个文件存到 我的文档\LianqinHost\录音。键盘 1–5 按对应轨，0 全部播放 / 停止。
      每轨最长 30 秒。
  - “阶梯…”（速度旁边）：开启后在 A-B 循环里从慢速开始，弹稳了自动提速，直到目标速度。
  - 顶部“练习记录”：每天练了多久、连续几天、每首歌的成绩变化。

五（续）、指板音阶（顶部“指板音阶”页签）
  - 选根音和音阶：五声、布鲁斯（都可切大调 / 小调）、七声音阶（大调 / 自然小调 / 和声小调 / 旋律小调）、
    教会调式（伊奥尼亚、多利亚、弗里几亚、利底亚、混合利底亚、爱奥利亚、洛克里亚）。
  - 把位：全指板，或者一个个把位看（五声 / 布鲁斯是 5 个标准框，七声音阶是每弦三音）。当前把位实色，其余淡色。
  - 红点是根音，蓝点是音阶音，紫点是蓝调音；圆点里可以显示音名或级数。点任何一个音可以试听。
  - “示范”：按当前把位弹一遍（上行 / 下行 / 上行再下行，速度可调，可循环）。
  - 右上角可以换乐器：吉他 6 弦 / 贝斯 4 弦 / 贝斯 5 弦 / 吉他 7 弦，指板、把位、认音训练都会跟着变。
  - 你弹的音会实时用黄圈标出来，告诉你在不在音阶里、是几级。
  - “跟弹练习”：绿圈是下一个要弹的音，弹对了自动跳到下一个，弹完一遍记一遍。
  - 下面是鼓机，可以一边放鼓一边看音阶即兴。“配鼓”里有 14 套鼓点，带 ★ 的是适合当前音阶的推荐；
    点“按音阶配鼓”一键换上（比如小调布鲁斯配慢 Shuffle，多利亚配放克，和声小调配金属）。
  - 识别用的是没过效果器的干声；门槛跟着你的底噪自动调，高音弦也能认出来。
  - “认音训练”（Q 键）：熟悉指板上每个位置是什么音。
      看位置说音名：指板上亮一个橙点，点下面的音名按钮（或按键盘 C D E F G A B，Shift = 升半音）。
      看音名找位置：给一个音名，把范围里它所有的位置都弹出来（用吉他弹，程序听）或者在指板上点出来。
      可以只练某几根弦（先练 6 弦、5 弦）、某一段品格（0–5、0–12、5–12 …），可以只出自然音。
      下面显示正确率、平均用时、连对次数和最容易错的音。
  - 快捷键：空格 示范 / 停止，← → 换把位，↑ ↓ 换根音，F 跟弹练习，Q 认音训练，D 鼓机开 / 停。

五（续二）、吉他和弦（顶部“吉他和弦”页签）
  - 上面选根音和和弦类型（大三、m、7、maj7、m7、sus2、sus4、add9、5、dim、dim7、m7b5、aug、6、m6）。
  - 下面列出几种指法：开放和弦、E 型横按、A 型横按、D 型……，圆点里是用哪根手指（1 食指 … 4 小指），
    × 是不弹，○ 是空弦，“5fr”表示从第 5 品开始。点一张卡片试听（空格扫弦，A 分解）。
  - “调内和弦”：选一个调（大调 / 小调，可切七和弦），列出这个调的 7 个顺阶和弦（I ii iii IV V vi vii°），点一下选中。
  - “听我弹：看哪根弦没响”（L 键）：按好选中的指法扫一下，每根弦的点变绿 = 响了，变红 = 没响；
    灰色是和低音弦同名的音（比如 C 和弦里 2 弦的高八度 C），光听声音分不出来。
  - 下面同样有鼓机 / 循环 / 音频伴奏，可以跟着伴奏练换和弦。

六、设置和预设存在哪里
  %APPDATA%\LianqinHost\  （设置、练习记录）
  我的文档\LianqinHost\   （音色预设、录音）
  换电脑时把这两个文件夹一起拷走即可。
  压缩包里的“音色预设”“默认设置”是打包的人带过来的：第一次打开时自动导入，
  所以看到的音色、效果器、鼓机和练习设置和打包的人一样（声卡要自己在“音频设置…”里选）。
  音色库\Gervana 里是 Gervana 效果器的图片，换成同名图片就能换掉软件里显示的样子。
  吉他谱\       谱库、你放进去的谱子；吉他谱\扒谱\ 是“扒谱…”生成的谱子。

六（续）、Mac 版
  - 打开 .dmg，把“老干部活动中心.app”拖到“应用程序”。第一次打开要右键 → 打开（程序没有苹果开发者签名）；
    提示“已损坏”时在终端里运行：sudo xattr -dr com.apple.quarantine /Applications/老干部活动中心.app
  - 第一次会问能不能用“麦克风”：要点允许，这是读取声卡里的吉他信号。
  - Mac 用系统自带的 CoreAudio，延迟本来就低，不需要 ASIO。功能和 Windows 版一样。
  - 自己的谱、扒谱、录音、音色预设都在“文稿/LianqinHost”里；分离模型放在“老干部活动中心.app”旁边的 models 文件夹。
  - 自己编译：在 Mac 上运行源码里的 build_mac.sh（需要 Xcode 命令行工具和 CMake），会生成 发布/老干部活动中心-v版本-mac.dmg。
